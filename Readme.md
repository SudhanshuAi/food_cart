# Food Cart Frontend Web App

## Overview
This is a simple frontend web application for a food cart, developed using HTML, CSS, and JavaScript. The application provides users with an interactive interface to browse food items, add them to their cart, and proceed to checkout.

## Features
- Responsive design for various screen sizes
- Interactive food menu with images and descriptions
- Add-to-cart functionality
- View and update cart items
- Simple checkout process

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/food-cart-frontend.git
   ```
2. Navigate to the project directory:
   ```sh
   cd food-cart-frontend
   ```
3. Open `index.html` in a web browser.

## Usage
- Browse available food items.
- Click "Add to Cart" to add items.
- View cart and update quantities as needed.
- Click "Checkout" to finalize the order.
